# Agents: understanding agent systems from first principles

This repository is a journey to understand agent systems from first principles.
We will ask questions, explore the ideas in code, and build toward something
useful by the end.

Rather than starting with a framework or treating agents as a black box, the
journey will uncover the pieces an agent system needs and why. Each step should
build on what came before, making the reasoning and tradeoffs visible.

The path is intentionally open-ended. As we learn, we will decide what to
explore next and use those questions to shape what we build.
